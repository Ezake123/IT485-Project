Help and Preparation Guide

Follow these instructions to acquire your official degree audit and register with your selected class codes in WISER.

How to get degree audit

  1. Log into WISER, you can do it from here.
  2. Find and click Boston Degree Audit on the main page.
  3. Click Run Current Program without adding or changing anything.
  4. Wait for the audit to be created. If you see a list of audits, wait for the newest one to be created and click view pdf.
  5. Click Download PDF Audit or the download button in the pdf viewer.

How to use the class code

  1. Click on the code number to copy it.
  2. Log into WISER, you can do it from here.
  3. On the left side of the main page, click Enrollment, the dropdown.
  4. Select Enrollment: Add Classes.
  5. Select the correct term you have generated the schedule with.
  6. Find Enter Class Number near the middle-left of the screen and enter the code you copied then press enter.
